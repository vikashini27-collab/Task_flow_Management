TASKFLOW

Task Management System

A full-stack productivity platform with beautiful pastel UI, 3D animations, real-time task tracking, team collaboration, and smart deadline reminders.

React + TypeScript Spring Boot Three.js JWT Auth

Presented by Vikas · September 2026

SLIDE 02

Problem Statement

😵

Scattered Task Tracking

Teams use sticky notes, spreadsheets, and chat messages to track work — leading to missed deadlines and lost tasks.

📅

No Deadline Reminders

Without automatic alerts, important deadlines slip through the cracks causing project delays and stress.

👥

Poor Team Coordination

No easy way to invite friends or teammates to collaborate on shared projects and task plans.

📊

No Visual Analytics

Existing tools lack cute, visual dashboards showing completion rates, weekly trends, and progress charts.

SLIDE 03

Our Solution: TASKFLOW

A beautiful, full-stack task management system with a pastel-themed UI, 3D cloud animations, smart reminders, and real-time collaboration features.

✅

Full CRUD Tasks

Add, Edit, Delete with date, priority & status

🔔

Smart Reminders

Auto-alerts 2 days, 1 day before deadline

👥

Team Invites

📊

Live Analytics

Pie charts, area graphs from real data

☁️

3D Animations

Floating clouds, moon, sparkles with Three.js

🎨

Theme System

Light/Dark mode with pastel color presets
